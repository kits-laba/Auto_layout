# Auto_layout
Auto Layout is a Geode mod that builds a simple, playable layout for your song in one click.
Features
Set a Newgrounds song by ID
Automatic BPM, length and first-beat detection (or enter them manually)
Spikes and blocks placed on the beat grid
Adjustable density (sparse, medium, dense)
Fair spacing: every obstacle leaves enough room to jump
Usage: open the editor pause menu and press Auto Layout. Configure the song ID, BPM and density in the mod settings.
